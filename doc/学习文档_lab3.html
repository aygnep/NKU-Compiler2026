先认识这些术语

张量、秩与形状
这里的张量是 int 或 float 元素组成的多维值。秩是维度个数，形状是各维长度，例如 [2,3] 的秩为 2。
逐元素与矩阵乘法
a*b 将对应元素相乘，要求形状相同；a@b 做矩阵乘法，[M,N]@[N,P] 得 [M,P]。
标量提升
a+2 中先把 2 看作每个元素均为 2 的同形状值。IR 不创建这个广播数组，而是在循环中复用同一个标量。
静态与动态维度
声明中的维度是正整数常量；张量形参第一维写 []，其实际长度由调用者通过隐藏的 i32 参数传入。
类型与属性
TensorType 保留元素基类型，ExprNode::tensorShape 记录形状；张量不能因底层也是连续内存就当作普通数组或标量。
ABI 与返回缓冲
ABI 是调用双方约定的参数传递方式。张量参数传 ptr+首维；张量结果由调用者分配空间，以隐藏输出 ptr 接收，LLVM 函数返回 void。
SSA 与 PHI
SSA 寄存器只定义一次。IR 循环的索引 PHI 根据入口或回边选当前值；矩阵乘法另有求和累加。
函数序言与生命周期
函数序言先准备参数和临时空间，再进入函数体。临时 alloca 每次调用只分配一次，避免循环每轮扩大栈。
形状检查与 trap
静态能确定的不匹配在编译时拒绝；两个未知首维在运行时比较，不一致或结果容量溢出时调用 llvm.trap。

跟着一个输入走完整个过程

1. 先用四个元素走完流程

输入：int main(){tensor int a[4]={1,2,3,4};tensor int b[4]={5,6,7,8};tensor int c[4]=a+b*2+10;return c[0];}
Bison 按优先级建立 a + (b * 2) + 10。a、b 的类型均为 tensor int，形状 [4]；两个标量都是 int，与张量基类型相同。b*2 得 [10,12,14,16]，再加 a 和 10 得 [21,24,27,30]，返回 21。tensor_elementwise 回归逐个输出 c、d、e、f、g 的所有元素，独立检查加、乘、除、取模与提升。

类型检查与中间代码生成实验手册.pdf（26 页，新版） · PDF 第 10–11 页：逐元素运算

2. 从关键字到可检查的形状

lexer.l 在标识符前识别 tensor 并识别 @。yacc.y 在 TYPE 中组合 tensor int/float，并把 @ 放入 MULDIV_EXPR，和 * / % 同层、左结合。AST 保存 TensorType 与 tensorShape；普通数组仍按旧规则处理，张量整体读取保留张量类型，完整下标才得到一个标量。a[0] 对二维张量是部分下标，因此被拒绝；a[0][1] 合法。

张量实现要求.pdf（3 页） · 第 1 页，红色修订文法：TensorType → 'tensor'

3. 整体运算怎样变成 IR

代码生成器用 TensorValue{ptr,dims} 表示一个张量值。逐元素循环采用 i=0…count-1，用 GEP 取两个元素地址，load 后生成 add/mul 等，再 store 到独立结果缓冲。标量表达式在进入循环前只算一次，例如 a+bump() 不会给每个元素调用一次 bump。赋值先拍下完整右值再复制，避免 a=a@a 或别名参数覆盖尚未读取的元素。

类型检查与中间代码生成实验手册.pdf（26 页，新版） · PDF 第 10–11 页：标量提升

4. * 与 @ 的结果确实不同

输入 A=[[1,2],[3,4]]、B=[[5,6],[7,8]]：A*B 得 [[5,12],[21,32]]；A@B 得 [[19,22],[43,50]]。@ 的输出第 (i,j) 项按 k 累加 A[i,k]*B[k,j]。tensor_matrix 使用手册的 [2,3]@[3,2]，实际输出 58 64 139 154；tensor_precedence 额外验证 A@B*C 是先矩阵乘，再逐元素乘。

类型检查与中间代码生成实验手册.pdf（26 页，新版） · PDF 第 10–11 页：Hadamard

5. 首维 [] 如何在函数里工作

void add(tensor int a[]){a=a+2;} 在 LLVM 中接收一个 ptr 和一个隐藏 i32 长度。调用者对长度 3 和长度 5 的张量分别传入 3、5，函数体依据实际长度生成循环。自定义函数尾维在语义阶段校验；同一函数内两个未知首维参与运算/赋值时，IR 比较实际值。tensor_parameter 同时验证不同长度调用；dynamic_elementwise/dynamic_copy 验证运行期不匹配被拒绝。

类型检查与中间代码生成实验手册.pdf（26 页，新版） · PDF 第 11–12 页：第一个维度必须留空

6. 返回局部张量为什么不会悬空

tensor int make(int x){tensor int a[2]={x,x+1};return a;} 的返回形状从声明与 return 推断为 [2]。调用者先分配输出缓冲，将指针作为隐藏首参数；被调用者在 return 前复制两个元素到那里，再 ret void。返回局部数组地址的做法会在函数退出后悬空，本实现不采用它。形状预读先看完整函数体，允许递归调用写在固定尺寸基本分支之前；正式检查仍逐个核对所有 return 的类型与形状。

类型检查与中间代码生成实验手册.pdf（26 页，新版） · PDF 第 11–12 页：返回张量的尺寸在编译时已知

7. 循环里做张量运算也要考虑空间

tensor_dynamic_loop 在函数中对动态首维张量连续做 10000 次 a=a+1。生成器把临时缓冲计数、容量检查和 alloca 放在函数序言，并维护序言到函数体的边；函数体中的数值循环只读取和更新已有缓冲。声明变量仍按原规则初始化。dynamic_result_size 验证输入对象分别合法、但矩阵乘积容量过大时，在分配前拒绝。
